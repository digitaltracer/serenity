# @serenity/macos

Native macOS app target for Serenity, implemented in SwiftUI.

## Local development

- Build: `npm run build --workspace @serenity/macos`
- Test: `npm run test --workspace @serenity/macos`
- Run locally: `npm run dev --workspace @serenity/macos`

You can also open `apps/macos/Package.swift` directly in Xcode for native development workflows.

On non-macOS systems, npm workspace scripts for `@serenity/macos` no-op by design.
